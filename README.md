# Exponent Game
A roguelike incremental/exponential game with prestige mechanics.

## Structure Overview
- `src/hooks/`: Contains the core mathematical game loop and synergy calculators.
- `src/components/`: React UI components for the board, item drafting (roguelike element), and prestige.
- `src/data/`: Static definitions of the item pool and exponential checkpoints.
- `src/types/`: TypeScript definitions ensuring strict typing for game state and synergies.
